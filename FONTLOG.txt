FONTLOG for Heldenlied Minuskel
===============================

This file provides detailed information on the Heldenlied Minuskel
Font Software. This information should be distributed along with the
Heldenlied Minuskel fonts and any derivative works.


Basic Font Information
----------------------

Heldenlied Minuskel is a Carolingian minuscule display typeface
inspired by and modelled on the Folchart Psalter (St. Gallen, Stiftsbibliothek,
Cod. Sang. 23, 9th century). It was created for the tabletop RPG
"Heldenlied – Das Schicksal der Helden" (https://heldenlied-rpg.de)
and is intended for titles, logos, handouts and atmospheric text.

Glyphs are drawn in Inkscape; the font source is a UFO, built with fontmake.
OpenType features: ccmp, liga, rlig, calt, locl, hist, mark, kern, stylistic sets
(see README.md).


ChangeLog
---------

2026-10-18 (Richard Westebbe) Heldenlied Minuskel Version 0.5
- Completed the Google Fonts Latin Core character set (GF_Latin_Core)
- Added accented letters for Western, Central and Northern European
  languages (acute, grave, circumflex, caron, breve, ring, ogonek,
  cedilla, comma accent, double acute, dot accent, tilde), built as
  composites, plus ø, ð, ł, đ and ħ
- Added thorn and Thorn (lightened bowl compared to the original)
- Added spacing accents, combining accents with mark anchors, and
  symbols and punctuation: @ # % & * § ¶ © ® ™ °, dotted cross (U+205C),
  € £ ¢ ¥ $, + − × ÷ = < >, brackets, braces, guillemets, ellipsis,
  bullet, reference mark
- New locl feature: Catalan punt volat (l·l via periodcentered.loclCAT)
  and Turkish/Azerbaijani/Crimean Tatar dotted and dotless i
- Glyph names now follow Fontra's naming (e.g. macroncomb instead of
  uni0304, idotless instead of dotlessi); SVG sources renamed to match
- Respaced all letters from a uniform starting point (tight letter
  spacing kept on purpose)
- First class-based kerning: about 1,360 pairs in 95 kerning groups for
  letters and punctuation
- ť, ď, ľ and Ľ use a dedicated caron (caroncomb.alt) instead of the
  regular caron; a combining caron after d, l, L and t takes the same
  form (ccmp)
- i and j lose their dot before combining accents above (ccmp), e.g.
  Dutch íj́
- Mark anchors added to j and r and propagated to composite glyphs
  during the build, so stacked accents attach correctly
- On-curve points within 2.5 units of baseline, x-height and ascender
  snapped onto these lines (scripts/snap_alignment.py); extreme point
  added to the hook of ȷ (TTF exceeded usWinDescent)
- Added a meta table (designed and supported script: Latn); shortened
  the name table descriptions to under 200 characters
- Build: TTF components are flattened; Fontbakery reports are written
  as JSON (fonts/fontbakery-report-*.json) and summarised in the console
- OFL.txt now matches the official license text word for word

2026-09-26 (Richard Westebbe) Heldenlied Minuskel Version 0.4
- Switched the source format from FontForge (.sfd) to UFO;
  OpenType features are now maintained as plain text (features.fea)
- Added build script (scripts/build.py) producing OTF, TTF and WOFF2,
  optionally with Fontbakery checks and release ZIPs per format
- Added automated feature tests and test documents (tests/)
- Modern letterforms are now the default; the former ss06 forms became
  the base glyphs, historical forms were renamed to *.hist
- Historical forms moved to the new feature hist, mirrored in ss20:
  long s, ss as ß, u/uu/i forms, umlauts with superscript e, historical
  ß, punctuation, Roman numerals and late medieval numerals
- New ss05: Roman numerals 1–3999 in additive notation (also part of
  hist/ss20); previously 1–100 in calt. A period or comma directly after a
  number merges into the closing punctus, dates become e.g. ·xxui·uiiii·dccclxxii·;
  decimal numbers and times (3,5 / 12:30) stay unchanged
- New ss07: late medieval numerals 5 and 7 (also part of hist/ss20);
  ss07 takes precedence over Roman numerals, so hist + ss07 shows
  late medieval digits instead of Roman numerals
- ss06 is no longer used; ss02–ss04 are reserved for capital sets
- ss01 now also applies to the capitals B, D, H, K and L
- Added ccmp: dotless i before a combining macron
- Titulus: same height on all letters (precomposed and combining),
  stroke made thicker
- Ligatures and shortened f crossbar now also apply to the capitals F
  and T, which still show lowercase forms (e.g. Föhn, Tisch)
- ss01: new ligatures f_l.ss01 and longs_l.ss01 for f/ſ before the tall l
  (placeholder composites, final shapes to follow)
- Removed redundant glyphs zero.ss06–nine.ss06 (except 5, 7) and s.ss06
- Cleaned up tiny leftover curve segments from vectorisation
  (overlapping path segments)
- Capital macron vowels (Ā Ē Ī Ō Ū) no longer use nested components
- Added ligature caret positions for all ligatures
- TTF/WOFF2: smart dropout control enabled (unhinted font)
- OS/2 fsSelection USE_TYPO_METRICS set again (lost in the UFO export)
- Fixed style linking (styleMapFamilyName) and restored the German
  name records for description and sample text
- Fixed: "Auss…" at the start of a word was converted to ß

2026-09-24 (Richard Westebbe) Heldenlied Minuskel Version 0.3
- First public release
- Redrawn c, g, o, p, t, v and z based on the Folchart Psalter
- Optimised the width of h
- Raised o to provide proper overshoot
- Harmonised entry strokes and serifs across all glyphs; sidebearings reset
- Added umlauts ä, ö, ü in the historical form with superscript e
- Added æ and macron vowels ā, ē, ī, ō, ū
- Added combining macron (U+0304) with mark attachment (GPOS)
- Added period and semicolon
- Added historical punctuation: reversed semicolon (U+204F) and
  punctus elevatus (U+2E4E)
- v, w and j now show historical forms by default (u-, uu- and i-forms);
  modern forms available in ss06
- Added ligatures f_f and longs_longs to resolve ascender collisions
- Added glyphs f.asc, f_f.asc, longs.asc and longs_longs.asc
  (shortened crossbar before ascenders)
- Added late-medieval numerals (modern numerals in ss06)
- Added z glyph as ß (ß contained in ss06)
- Automatic replace of ss with z for historical correctness
- Uppercase codepoints temporarily mapped to lowercase forms
  until dedicated capitals are available
- Renamed stylistic set "Modern readability" from ss04 to ss06;
  ss06 now also contains two-dot umlauts and modern w
- Added German and English feature names for ss01 and ss06
- Removed DSIG table and Mac platform name records
- Removed all kerning; kerning will be rebuilt in a later version
- Automatic conversion of numbers 1–100 into Roman numerals (calt)
- Added t_t ligature
- Added symbols & and §
- Long s (ſ) used throughout by default, as in the Folchart Psalter; round s in ss06

Versions 0.1 and 0.2 were unpublished internal development versions.
